# Changelog

All notable changes to Task Timeline will be documented in this file.

## 1.0.0 - 2026-09-13

### Added

- Automatic archiving of completed checklist items.
- Date-grouped completed-task timeline.
- Configurable to-do file, completed file, date format, and date ordering.
- Preservation of indented child content.
- Manual archive command.
- Reading-view timeline styling.
- Vault-relative path normalization and optional `.md` extensions.
- Legacy cleanup for notes created during pre-release development.
